# Native Mods tabs implementation plan

**Approved design:** Settings gains a top-level Mods tab and a horizontal Tankmate Signal inner tab. The page contains only Message hotkey and a Dev mode checkbox with its test-shortcut description. Dev mode defaults off and persists across launches. It unlocks Ctrl+F9 / Ctrl+F10, without automatic samples. Apply/OK saves both values; Cancel discards pending edits. Remove the Controls group. No external settings mods are required.

**Architecture:** Bundle a small extension of the client's Settings SWF, built from its native SettingsWindowUI and native component library. Redirect only the Settings view URL to this packaged SWF, leaving the original client resources untouched. The extension intercepts its own Mods tab selection and provides native tabs, key field, checkbox, and labels; all existing Settings tabs and buttons retain their original handlers. Python receives mod changes through the existing Settings callback, validates bindings, and persists both values together.

**Verified 2026-11-25:** All 46 regression tests and archive verification pass. Python 2.7 compilation and hook cleanup were checked against the client runtime. The installed client shows both tab levels, the native dark background, full-width divider, and an unclipped key caption. Switching to Controls and back works; toggling Dev mode enables Apply, and Cancel discards the edit without changing the saved configuration. Synthetic keyboard input did not change the capture field, so physical key capture and Apply/restart persistence still need a manual client check; their model behavior is covered by the regression tests.

**Layout correction:** The native ViewStack has a 10 × 10 timeline placeholder. Its width and height are not the tab content bounds. The extension now uses the stock 802 × 523 content rectangle and retains KeyInputUI's natural 134 × 28 dimensions. Components use the native IndexEvent and typed tab data, SmallTabButton, Window_BGForm, FieldSet, and embedded Settings text style.
